## 技術ノート

### FLUENT API の実装

Fluent API（メソッドチェーン）を設計する際,
メソッド呼び出しの順序を任意（順不同）にしつつ,
コンパイル時に呼び出し漏れや重複を検証しようとすると,
作成すべきインターフェースやメソッドの数が
階乗の規模で爆発的に増加する問題が発生.
解決策は

- メソッド呼び出しの順序を任意（順不同）, を断念
- コンパイル時における呼び出し漏れや重複を検証, を断念

本アプリケーションでは基本的に JavaScript インタープリタから
Java クラスを呼び出す構造であり, JavaScript コード開発時に
IDE の補助が期待出来ない. ゆえに後者を採用するものとする.
ただし小規模な場合は愚直に FLUENT API を実装する.
